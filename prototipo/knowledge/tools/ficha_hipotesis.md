# Ficha de hipótesis y criterios de validación
> Borrador para validar con Cubides (estructura general de la herramienta).

## Qué es
Herramienta de **Alistamiento del experimento** (etapa 5) para definir qué se va a probar y cómo se sabrá si funcionó.

## Cuándo se usa
Antes de ejecutar un experimento, para que sea medible (enfoque Lean Startup).

## Cómo se usa (paso a paso)
1. Redacta la **hipótesis**: "Creemos que [acción/solución] logrará [resultado] para [usuario]."
2. Define la **métrica** que lo demuestra.
3. Define el **criterio de validación** (umbral): "Lo sabremos si [métrica] alcanza [valor]."
4. Describe el **experimento** mínimo para probarlo.

## Qué entrega
Una ficha con: hipótesis, métrica, criterio de éxito y experimento propuesto.
