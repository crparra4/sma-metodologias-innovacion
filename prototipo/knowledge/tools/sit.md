# SIT — Systematic Inventive Thinking
> Borrador para validar con Cubides (Compensar usa SIT; confirmar patrones exactos).

## Qué es
Metodología de **Ideación estructurada** (etapa 4): genera ideas "dentro de la caja",
trabajando sobre el producto/servicio que ya existe con patrones definidos.

## Cuándo se usa
Para innovar de forma sistemática, sin partir de una hoja en blanco.

## Cómo se usa (paso a paso)
Aplica cada patrón al producto/servicio actual:
1. **Sustracción** — quita un componente esencial y observa qué surge.
2. **División** — separa el producto en partes y reorganízalas.
3. **Multiplicación** — duplica un componente cambiándolo.
4. **Unificación de tareas** — asigna una nueva función a un componente existente.
5. **Dependencia de atributos** — haz que dos atributos varíen juntos.

## Qué entrega
Una lista de ideas generadas con cada patrón SIT.
