# SCAMPER
> Borrador para validar con Cubides (estructura general de la herramienta).

## Qué es
Técnica de **Ideación** (etapa 4) que transforma una idea aplicándole 7 lentes.

## Cuándo se usa
Para generar variantes y mejorar una idea o solución existente.

## Cómo se usa (paso a paso)
Toma la idea base y aplícale cada lente, anotando lo que surja:
- **S**ustituir — ¿qué se puede reemplazar?
- **C**ombinar — ¿qué se puede unir?
- **A**daptar — ¿qué se puede ajustar de otro contexto?
- **M**odificar — ¿qué se puede aumentar/reducir?
- **P**oner otros usos — ¿para qué más sirve?
- **E**liminar — ¿qué se puede quitar?
- **R**eorganizar/invertir — ¿qué se puede reordenar?

## Qué entrega
Una lista de ideas nuevas derivadas de aplicar las 7 lentes.
