# Iconos del acceso

`chatgpt.svg` (OpenAI) y `apple.svg`: Simple Icons 13.21.0, distribuido bajo CC0-1.0, descargados desde el paquete npm mediante jsDelivr. Se sirven localmente sin solicitudes externas del navegador. Las marcas pertenecen a sus respectivos titulares.

Google y Microsoft usan vectores multicolor en el HTML. Passkey y SSO son vectores de interfaz. Los seis métodos son reservas visuales deshabilitadas para integración futura, sin endpoints ni transmisión de credenciales.
